# أبطال القلعة

مشروع Flutter مستقل للعبة أسئلة عربية بواجهة كحلية وذهبية واتجاه RTL.

اللعب فردي أو تحدي محلي بين طرفين، مع أسئلة للأطفال والكبار وثلاثة خيارات للسؤال: سهل ومتوسط وصعب، ووسيلتي مساعدة. يُفتح المتوسط بعد إجابة سهلة، والصعب بعد ثلاث إجابات متوسطة، بشكل مستقل لكل لاعب. يُختار السؤال عشوائيًا ضمن المستوى، وتعرض الحجارة تقدّم اللاعبين نحو القلعة دون الضغط عليها. مؤقت السؤال 15 ثانية، والفوز عند 280 نقطة أو بأعلى رصيد عند نفاد الأسئلة المتاحة.

اللعب أونلاين: **تحدي 1×1 → اللعب أونلاين → فتح غرفة / الدخول إلى غرفة**. ينشئ المضيف كودًا من 5 أرقام وينتظر دخول اللاعب الثاني من جهازه، ثم تبدأ المباراة تلقائيًا. تفاصيل إعداد Firebase والنشر والاختبار في [docs/ONLINE.md](docs/ONLINE.md).

بنك الأسئلة: 190 للأطفال حتى 12 سنة، و280 للكبار من 13 سنة، مع مستويات صعوبة صريحة. تفاصيل مراجعة البنك وإضافة دفعات Excel في [docs/QUESTION_BANK.md](docs/QUESTION_BANK.md).
