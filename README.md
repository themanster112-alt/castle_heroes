# أبطال القلعة

مشروع Flutter مستقل للعبة أسئلة عربية بواجهة كحلية وذهبية واتجاه RTL.

النسخة الحالية: ثلاث فئات محلية، خمسة أسئلة لكل جولة، مؤقت 20 ثانية لكل سؤال، و100 نقطة للإجابة الصحيحة، وشاشة نتيجة وإعادة اللعب.

المنافسة المباشرة وربط قاعدة الأسئلة قادمان لاحقًا. الأسئلة الحالية تجريبية داخل `lib/main.dart`.

## التشغيل

```sh
flutter pub get
flutter run -d chrome
```

## الفحص

```sh
flutter analyze
flutter test
```
